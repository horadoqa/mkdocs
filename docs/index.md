# MKDOCS

**MkDocs** é uma ferramenta de código aberto usada para criar sites de documentação de projetos de forma simples e rápida.

Ela é muito popular entre desenvolvedores porque transforma arquivos escritos em Markdown (`.md`) em um site estático bonito e navegável.

### Em termos simples:

* Você escreve sua documentação em **Markdown**
* O MkDocs gera automaticamente um **site completo**
* Esse site pode ser hospedado facilmente (GitHub Pages, servidores, etc.)

---

### Principais características:

* ⚡ **Fácil de usar**: configuração simples com um arquivo `mkdocs.yml`
* 🎨 **Temas prontos**: como o famoso tema Material
* 🔍 **Busca integrada**
* 📦 **Plugins e extensões**
* 🚀 **Deploy rápido**

---

### Exemplo de uso:

Você cria arquivos como:

```
docs/
  index.md
  guia.md
mkdocs.yml
```

E roda:

```
mkdocs serve
```

Isso abre um site local para visualizar sua documentação.

---

### Quando usar?

* Documentação de APIs
* Guias técnicos
* Documentação de projetos open source
* Wikis internas de equipes

---

### Comparação rápida:

* MkDocs → simples e direto
* Sphinx → mais poderoso, porém mais complexo
* Docusaurus → mais focado em projetos modernos com React
